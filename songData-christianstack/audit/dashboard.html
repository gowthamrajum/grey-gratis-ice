Pipeline

Each stage writes to the live library only after the one before it is verified.

Defects found

Counted across all songs before any repair. The safe lane is mechanical — whitespace, invisible characters, stanza numbering — and needs no decision. The structural lane changes how a song is divided into chorus and verses, so every one of those is decided individually and re-checked before it is written.

Guardrail

Sanitisation may remove or re-partition text. It may never invent it. Before each write, every Telugu character in the proposed version is counted against the original — if any character appears more often than it did before, that song is rejected rather than written. A repair that would quietly reword a hymn cannot reach the database.
